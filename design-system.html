03 — Motion

Scroll Reveal

Elementy wchodzą z dołu. Obsługa przez IntersectionObserver. Klasa .visible dodawana automatycznie.

Element bez delay
class="reveal"
Z delay 100ms
class="reveal reveal--d1"
Z delay 200ms
class="reveal reveal--d2"
Z delay 300ms
class="reveal reveal--d3"
Z delay 400ms
class="reveal reveal--d4"
/* CSS */ .reveal { opacity: 0; transform: translateY(28px); transition: opacity 0.6s ease, transform 0.6s ease; } .reveal.visible { opacity: 1; transform: translateY(0); } .reveal--d1 { transition-delay: 0.1s; } .reveal--d2 { transition-delay: 0.2s; } .reveal--d3 { transition-delay: 0.3s; } .reveal--d4 { transition-delay: 0.4s; } /* JS */ const observer = new IntersectionObserver((entries) => { entries.forEach(e => { if (e.isIntersecting) { e.target.classList.add('visible'); observer.unobserve(e.target); } }); }, { threshold: 0.12, rootMargin: '0px 0px -40px 0px' }); document.querySelectorAll('.reveal').forEach(el => observer.observe(el));

04 — Usage

CSS Tokens — gotowe do skopiowania

Wklej ten blok na początku każdego nowego pliku CSS / <style>.

:root { /* ── Brand greens ── */ --green-dark: #1C5E3E; /* darkest, buttons/text on light */ --green-mid: #1C7C50; /* primary — btn-green, links, borders */ --green-light: #25A36A; /* hover state for green-mid */ --lime: #6BBF90; /* accent — pills, nav CTA on dark, eyebrow-light */ --lime-hover: #52A87A; /* hover state for lime */ --teal: #2EC48A; /* reserved for highlights / notifications */ /* ── Neutrals ── */ --cream: #F2F0E8; /* page background, input bg on light */ --cream-2: #E8E5DC; /* borders, dividers, pill borders */ --white: #FFFFFF; /* cards, footer, input bg */ --text: #0D0D0B; /* primary text */ --text-2: #3D3A35; /* secondary text, icons */ --text-3: #7A746D; /* body copy, descriptions */ --text-4: #A8A29C; /* placeholders, captions, muted */ /* ── Radii ── */ --r-sm: 8px; /* small chips */ --r-md: 16px; /* cards, rows */ --r-lg: 24px; /* major blocks, modals */ /* buttons/inputs: always 100px */ }
